# GIF Creator using Python
A simple Python project that combines multiple PNG images into an animated GIF using the ImageIO library.

## Features
- Convert multiple images into a GIF
- Lightweight and easy to understand
- Beginner-friendly Python project
- Customizable animation duration and looping
